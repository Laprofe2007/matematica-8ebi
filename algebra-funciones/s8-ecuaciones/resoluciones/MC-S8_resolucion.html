MC-S8 · Resolución explicada

Ejercicio 1 · Resolver ecuaciones (3 pts — 1 pt c/u)

a) 12m = 48

m = 48 ÷ 12
el factor 12 pasa a dividir
m = 4
S = {4}
Comprobación 12 · 4 = 48. ✓

b) 3h + 4 = 25

3h = 25 − 4
se resta 4 en ambos miembros
3h = 21
h = 7
el factor 3 pasa a dividir
S = {7}
Comprobación 3 · 7 + 4 = 21 + 4 = 25. ✓

c) 2x + (4x + 6) = 3x + (x + 2)

2x + 4x + 6 = 3x + x + 2
se eliminan los paréntesis
6x + 6 = 4x + 2
se reducen términos semejantes
6x − 4x = 2 − 6
transposición de términos
2x = −4 x = −2
el factor 2 pasa a dividir
S = {−2}
Comprobación 2(−2) + (4(−2) + 6) = −4 + (−2) = −6. 3(−2) + (−2 + 2) = −6 + 0 = −6. ✓

Ejercicio 2 · Conjunto solución (1 pt)

Se otorga el punto si el estudiante transcribe correctamente los tres resultados del Ejercicio 1 en notación de conjuntos:

S = {4} S = {7} S = {−2}
Nota docente las tres ecuaciones de este control tienen solución única (a ≠ 0). Los casos de "sin solución" (S = { }) e "infinitas soluciones" (S = {x / x ∈ Q}) se trabajan con ejemplos concretos en la Lección de Biblioteca "Lenguaje y equivalencia de ecuaciones", no están representados en este control por no contar con un ítem sourced de E03/E09 que ejemplifique esos dos casos sin construir una ecuación nueva.

Ejercicio 3 · Melissa y Mariángel (3 pts)

Melissa tiene 27 años, Mariángel tiene 11. Buscamos x = cantidad de años que deben pasar para que la edad de Melissa sea el doble de la de Mariángel.

27 + x = 2(11 + x)
27 + x = 22 + 2x
se elimina el paréntesis
27 − 22 = 2x − x
transposición de términos
5 = x
x = 5 Dentro de 5 años, Melissa (32) tendrá el doble de la edad de Mariángel (16).
Comprobación matemática 27 + 5 = 32. 2(11 + 5) = 2 · 16 = 32. ✓
Comprobación contextual 5 es un número entero y positivo, una cantidad de años razonable.

Ejercicio 4 · Un número desconocido (3 pts)

Llamamos x al número buscado. "El doble de un número aumentado en cinco" es 2x + 5; "el número disminuido en 3" es x − 3.

2x + 5 = x − 3
2x − x = −3 − 5
transposición de términos
x = −8
x = −8 El número buscado es −8.
Comprobación matemática 2(−8) + 5 = −16 + 5 = −11. −8 − 3 = −11. ✓
Comprobación contextual el enunciado pide "un número", sin restricción de signo ni de magnitud, así que −8 es una respuesta contextualmente válida.
