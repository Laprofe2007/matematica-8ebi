Suma y resta de polinomios — Resolución explicada

Matemática 8.° EBI · Reino Matemático 2026 · Liceo de Médanos

Adición de polinomios — recuadros a completar (pág. 17)
a
4x² + ▢ − 7x + 2 = 9x² − 7x + 2
Se necesita que 4x² + ▢ = 9x² → ▢ = 5x²
Respuesta: 5x²
b
−8x³ + ▢ + 4x² + ▢ − 16x + 0,1 = x³ + 5x² − 16x + 0,1
−8x³ + ▢₁ = x³ → ▢₁ = 9x³  |  4x² + ▢₂ = 5x² → ▢₂ = x²
Respuesta: 9x³ y x²
c
−7x² − 18x − 12 + ▢ = 0x² − 18x − 12
−7x² + ▢ = 0x² → ▢ = 7x²
Respuesta: 7x²
d
−5x² + 7x − 1 + ▢ + ▢ + ▢ = 0x² + 0x + 0
Cada monomio necesita su opuesto: −5x²→5x², 7x→−7x, −1→1
Respuesta: 5x², −7x y 1 (el polinomio −5x²+7x−1 y este resultado son polinomios opuestos)
Polinomios opuestos (pág. 18)
a
¿7m³ − 5m y −7x³ + 5x son polinomios opuestos?
7m³−5m + (−7x³+5x) = 7m³−5m−7x³+5x ≠ 0
No. Tienen variables distintas (m y x); aunque los coeficientes son opuestos, al sumarlos no se obtiene el polinomio nulo.
b
¿−a² − 0,1a + 3 y 0,1a − 3 + a² son polinomios opuestos?
(−a²+a²) + (−0,1a+0,1a) + (3−3) → 0
Sí. Mismos términos, coeficientes exactamente opuestos, misma parte literal → suman el polinomio nulo.
Rectángulo de lados variables — perímetro (pág. 18)
c
Rectángulo de lados m y 3m+1. ¿Qué expresiones representan el perímetro?
P = m + m + (3m+1) + (3m+1) = 8m + 2
OpciónExpresión¿Representa el perímetro?
i.sNo — no está definida
ii.8m + 2Sí
iii.10mNo
iv.m+m+3m+1+3m+1Sí (es el perímetro sin reducir)
v.4m+1+4m+1Sí (equivalente a 8m+2, aunque agrupa distinto)
vi.m+3m+1No — es solo la mitad del perímetro (4m+1)
Correctas: ii, iv y v (las tres se reducen a 8m + 2).
d
¿Para qué valor de m el perímetro es 86?
8m + 2 = 86 → 8m = 84 → m = 10,5
Respuesta: m = 10,5
Sustracción de polinomios (pág. 19)
·
Inventar dos polinomios cuya diferencia sea 3x² − 9x + 10
Ejemplo: (4x² − 5x + 12) − (x² + 4x + 2) = 3x² − 9x + 10
Es una consigna abierta — cualquier par de polinomios que verifique la resta es válido. Este es solo un ejemplo de verificación.
·
Asocia cada resta con el polinomio que falta
RestaCálculoPolinomio que falta
1. ▢ − (5x−1) = −x+4▢ = (−x+4)+(5x−1)4x + 3 (opción d)
2. (4x²−2x+1) − ▢ = −x²−4x+2▢ = (4x²−2x+1)−(−x²−4x+2)5x² + 2x − 1 (opción a)
3. (−x+18) − (x²−12x+1) = ▢−x+18−x²+12x−1−x² + 11x + 17 (opción c)
4. (7x²−4) − ▢ = 0▢ = 7x² − 47x² − 4 (opción b)
1→d, 2→a, 3→c, 4→b (cada opción se usa una sola vez).
Sobre la "Sopa de monomios" (pág. 18): es una actividad de verificación visual con recorte de colores (Bruno circula pares con un mismo color). No incluí una resolución escrita porque depende de la manipulación directa del material impreso — se corrige en el aula comparando las producciones del grupo, como sugiere la propia consigna del libro.
