F11 · Resolución explicada

Parte 1 · La tabla

xJosé: f(x) = 500x + 35.000Ana: g(x) = 700x + 25.000¿Quién gana más?
1040.00032.000José
2045.00039.000José
6065.00067.000Ana

Con pocas computadoras vendidas, José gana más (tiene el salario base más alto). Pero en algún punto Ana lo alcanza y lo supera, porque su comisión por computadora es mayor.

Parte 2 · El punto de encuentro

Buscamos el valor de x para el que ambos salarios son iguales: f(x) = g(x). Igualamos las dos expresiones:

500x + 35.000 = 700x + 25.000
500x + 35.000 − 500x = 700x + 25.000 − 500x
se resta 500x en ambos miembros
35.000 = 200x + 25.000
35.000 − 25.000 = 200x + 25.000 − 25.000
se resta 25.000 en ambos miembros
10.000 = 200x
10.000 : 200 = 200x : 200
se dividen ambos miembros entre 200
50 = x
x = 50 Cuando venden 50 computadoras cada uno, José y Ana ganan exactamente lo mismo.
Comprobación José: f(50) = 500 · 50 + 35.000 = 25.000 + 35.000 = 60.000. Ana: g(50) = 700 · 50 + 25.000 = 35.000 + 25.000 = 60.000. Ambos ganan $ 60.000: se cumple la ecuación.

Con menos de 50 computadoras, José gana más (como se ve en la tabla con x = 10 y x = 20). Con más de 50, Ana termina ganando más (como con x = 60). El valor x = 50 es exactamente el punto donde se cruzan las dos situaciones.

Para pensar y responder Igualar las dos expresiones es preguntarse para qué cantidad de computadoras los dos salarios dan el mismo resultado. Es la misma idea de F10, cuando se buscó la cantidad que daba un salario de $ 55.000, pero ahora el otro miembro no es un número fijo: es otra expresión que también depende de x. En las próximas clases, este tipo de relación entre x y f(x) va a tener un nombre propio.
