Una misma relación

Una relación puede representarse mediante un enunciado, una tabla, una expresión y una gráfica. Ahora vas a distinguir dos tipos de funciones a partir de su expresión y de su gráfica.

Función afín

Una función afín tiene la forma f(x) = ax + b, donde a y b son números fijos. Si trabajamos con todos los números reales, su gráfica es una recta. En las funciones de primer grado, a ≠ 0.

Función lineal

Cuando b = 0, la expresión queda f(x) = ax: se llama función lineal. Su gráfica completa pasa por el origen (0, 0). Es un caso particular de función afín. Para x ≠ 0, el cociente f(x)/x es constante.

Afín no lineal

Cuando b ≠ 0, la función es afín no lineal. Su gráfica completa no pasa por el origen: para x = 0, la imagen es b.

Dos ejemplos que ya conoces

Fábrica de Pintura, receta de F05 con k = 2: f(x) = 2x. A 0 L de rojo corresponden 0 L de verde: función lineal. Taxi de F06: c(k) = 60k + 50. Para 0 km, el costo es $50: función afín no lineal. Los precios del taxi son ficticios.

Representar a partir de una expresión

Elige valores de x del dominio, calcula sus imágenes y organiza los pares en una tabla. Ubica los puntos en los ejes y traza la recta que los contiene. Comprueba que todos los pares de la tabla pertenecen a ella. En un contexto, representa solamente las entradas que tienen sentido.
